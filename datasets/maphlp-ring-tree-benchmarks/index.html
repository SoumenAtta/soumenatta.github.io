About these tables

The two tables reproduce the first four columns of the manuscript appendix. A fifth column provides the matching .dat file. Each data file is shared across five values of α and both topologies; α and topology are model settings, not separate data files.

n
Number of demand nodes, each also a candidate hub location.
p
Number of hubs to open and distinct content segments to place.
α
Inter-hub transportation cost multiplier. The values 0.2, 0.4, 0.6, and 0.8 give a discount; α = 1.0 gives no discount.
zBKS
Best-known solution cost: the smallest feasible objective found for this case across the direct Gurobi solve and all 30 standalone and hybrid runs. Costs use the original instance units.
*
Gurobi certified the best-known cost within the relative mixed-integer programming gap tolerance of 10−4. An unmarked cost has no such certificate.
Instance data
Downloadable file containing query-volume matrix Q and distance matrix D. In Q, an entry is the request volume from a node for a segment; in D, an entry is the distance between two nodes.

The remaining appendix columns—solution source, segment-host assignments, and ring order or tree parent vector—remain in the manuscript.
